# メモアプリケーション

## 概要
- このアプリケーションは、常に最前面に表示されるシンプルなチェックリスト型メモアプリです。

## 特徴
- タスクの追加・編集・削除
- チェックボックスによるタスク完了状態の管理
- ダブルクリックによるタスク編集
- 日報用にタスク一覧をコピー（未完了・完了タスクを自動分類）
- 常に最前面に表示

## 開発背景
- 常に最前面に表示されるメモアプリが欲しく作成しました。

## 技術スタック
- Electron
- HTML/CSS/JavaScript
- Node.js

## セットアップ・使用方法

### 動作確認時の条件
- Node.js(22.14.0)
- npm(10.9.2)

### アプリケーションの起動

#### 開発モードで実行

```bash
# 依存パッケージをインストール
npm install

# アプリケーションを起動
npm start
```

### アプリケーションの使用
- アプリを起動する
- `+` の横にあるテキストボックスにタスクを入力してEnterキーを押す
- タスクが追加される
- タスク領域内をダブルクリックして編集（テキスト部分だけでなく、枠内ならどこでもクリック可能）
- チェックボックスをクリックしてタスク完了をマーク
- 「日報用にコピー」ボタンをクリックして、日報形式でタスク一覧をクリップボードにコピー

以下、「日報用にコピー」の結果となります。
```txt
【2025/5/27の作業内容】

【未完了】
・タスクA
・タスクC
・タスクD-修正

【完了】
・タスクB
```
