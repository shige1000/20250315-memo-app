# メモアプリ

シンプルで使いやすいチェックリスト型メモアプリです。常に最前面に表示され、タスクの追加・編集・管理が簡単にできます。

## 機能

- タスクの追加・編集・削除
- チェックボックスによるタスク完了状態の管理
- ダブルクリックによるタスク編集
- タスク全体がボックス表示され、テキスト領域全体がクリック可能
- 日報用にタスク一覧をコピー（未完了・完了タスクを自動分類）
- 常に最前面に表示

## 技術仕様

- **オブジェクト指向設計**: コードはクラスベースで構造化されています
  - `ElementManager`: DOM要素への参照を一元管理
  - `TaskManager`: タスクの作成と編集ロジックを担当
  - `ReportGenerator`: 日報形式のレポート生成を担当
  - `TodoApp`: アプリケーション全体の管理
- **モダンなUI**: タスクは視認性の高いボックス表示
- **効率的なイベント処理**: イベント委任パターンを使用

## 開発環境のセットアップ

### 動作確認時の条件

- Node.js(22.14.0)
- npm(10.9.2)

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/memo-app.git
cd memo-app

# 依存パッケージをインストール
npm install
```

### 開発モードで実行

```bash
npm start
```

## exeファイルのビルド方法

Windows用の実行可能ファイル（.exe）を作成するには：

```bash
npm run build
```

ビルドが完了すると、`dist`フォルダに実行可能ファイルが生成されます。

## 使い方

1. アプリを起動する（開発モード: `npm start` または exeファイルをダブルクリック）
2. `+` の横にあるテキストボックスにタスクを入力してEnterキーを押す
3. タスクが追加される
4. タスク領域内をダブルクリックして編集（テキスト部分だけでなく、枠内ならどこでもクリック可能）
5. チェックボックスをクリックしてタスク完了をマーク
6. 「日報用にコピー」ボタンをクリックして、日報形式でタスク一覧をクリップボードにコピー

## コードの拡張ポイント

新機能を追加する場合は、以下のクラスを拡張するのが効果的です：

- 新しいUI要素の追加: `ElementManager`クラスを更新
- タスク管理機能の追加: `TaskManager`クラスを拡張
- 出力形式の追加: `ReportGenerator`クラスをベースに新しいジェネレータを作成
